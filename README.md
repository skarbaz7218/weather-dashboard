# Weather Dashboard

A responsive weather dashboard built using HTML, CSS, and JavaScript with the OpenWeatherMap API.

## Features
- Search weather by city name
- Display current weather conditions
- Temperature, feels-like temperature, humidity, and wind speed
- 3-day weather forecast
- Current location weather using geolocation
- Loading and error states
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Browser Geolocation API

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Add your own OpenWeatherMap API key in the JavaScript configuration.
4. Open `index.html` in your browser.
